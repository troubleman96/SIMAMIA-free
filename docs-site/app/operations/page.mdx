## Production checklist

- Set `CAMEL_ACCOUNTS_URL` to the trusted Camel Accounts issuer.
- Set `CORS_ALLOWED_ORIGINS` to the exact production app origin.
- Persist `/data/simamia.db` on durable storage and back it up off-server.
- Terminate TLS at the documented reverse proxy and expose only the proxy to the public network.
- Monitor `/api/v1/health`, application logs, disk space, and backup success.
- Run one API instance while SQLite is the storage backend.
- Keep example credentials, database files, and tokens out of source control and logs.

See the [Simamia monorepo deployment guide](https://github.com/troubleman96/SIMAMIA/blob/main/docs/deployment.md) for the existing VPS topology.
